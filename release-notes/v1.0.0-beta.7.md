## What's new

- **RetroArch core** - VBoy Color now also runs inside RetroArch (or any other libretro frontend) on Windows, Linux (x86-64 and ARM64, handhelds included), macOS and Android. It has the color packs built in, plus Auto, Multicolor, Gradient and Tint, and the 3D for a normal screen (side by side, top and bottom, colored glasses). RetroArch's save states, rewind, run-ahead, shaders and achievements all work. To install it, put the core in RetroArch's cores folder and `vboycolor_libretro.info` in its Core Info folder - without the `.info`, RetroArch shows only `.zip` games, not `.vb`. The zip's `INSTALL.txt` says where both go.
- **RetroAchievements** (softcore) - log in on the new Achievements page and earn achievements as you play. Unlocks pop up over the game, and the page lists every achievement with its badge. The login's keyboard has Copy and Paste (Ctrl+C / Ctrl+V on PC too) and an eye that shows the password as you type it.
- **Mario Clash** - Mario repainted part by part: a red cap and shirt, white gloves, dark overalls with gold buttons, and brown shoes, in every pose.
- **Wario Land** - Wario's nose stays pink when he dashes.
- **Dragon Hopper** - a second pass on its pack: the title screen, the story scenes and the fairies.
- **Smoother on Quest 3** - if you set the headset to 100 Hz with Quest Games Optimizer (or adb), VBoy Color now keeps that rate instead of switching to 120 Hz. The README explains how.
