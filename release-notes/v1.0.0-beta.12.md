## What's new

- **No more hiccups on laptops with two graphics chips** (Windows) - on a laptop with a built-in chip (like Intel Iris Xe) and a dedicated one (like NVIDIA), VBoy Color drew with the built-in one, and the game froze for about half a second every 12 seconds or so. It now uses the dedicated chip by default.
- **Settings > Screen > Graphics chip** (Windows and Linux, on a PC with more than one) - Automatic (the dedicated chip), Built-in (uses less battery) or Dedicated. A change is used the next time the app starts.
- **A button for the menu** - Settings > Button mapping has a new **Menu** row: pick any gamepad button (or key, on PC) and it opens the menu during a game. It's empty until you pick one, so nothing changes unless you set it. Thanks for the suggestion!
- **Nintendo Switch** (homebrew) - the RetroArch core now comes for the Switch too: a RetroArch with VBoy Color built in, for the SD card (see the table below and the INSTALL.txt inside). It's new and not tested on a real Switch yet - feedback welcome.

Your settings carry over from beta.11. Going back to an older version afterwards starts its settings from the defaults.
